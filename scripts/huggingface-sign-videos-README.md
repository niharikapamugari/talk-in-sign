# Talk in Sign — ISL video assets

This repository hosts the individual Indian Sign Language video clips used by
the Talk in Sign demonstration application.

## Source and attribution

The clips originate from the BridgeConn Sign Dictionary ISL dataset and are
made available under the Creative Commons Attribution-ShareAlike 4.0 license.
Any reuse or adaptation must retain appropriate attribution and use the same
license where required.

Source dataset: https://huggingface.co/datasets/bridgeconn/sign-dictionary-isl

## Layout

Each playable clip is stored at `signs/<number>.mp4`. The application maps
its gloss dictionary to these file names.
